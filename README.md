# Online Course Platform 🎓

A C# console application built using Object-Oriented Programming principles.

## Concepts Used
- Abstract Classes & Inheritance
- Encapsulation & Properties
- Polymorphism (virtual/override)
- Interfaces
- Enums, Structs
- Indexers
- Static Members
- Operator Overloading

## How to Run
Open in Visual Studio and run Program.cs
